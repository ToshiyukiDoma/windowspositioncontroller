# Windows Position/Size Controller
A very basic python script that allows you to control your windows screen's size and position.

![image](https://github.com/user-attachments/assets/e940dfcc-15fc-4e05-a0b1-01aaf6adb2ec)

Made purely with Google Gemini. I just do stupid funni wording for this to happen. xd

Made this particularly for Sound Voltex so I don't have to rotate my monitor for portrait setup as setting up and putting it back takes a lot of time and work to do.

This might be useful for some other cases so I didn't restrict it only for Sound Voltex.
